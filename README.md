 🚀 Projeto em destaque — Burger 301

 🍔 Inclusão Digital e Apoio a Pequenos Empreendedores

O **Burger 301** é um projeto desenvolvido em parceria com uma pequena hamburgueria local, como parte de uma atividade extensionista da faculdade.

O objetivo foi utilizar a tecnologia para apoiar um pequeno negócio, criando uma solução digital para melhorar a apresentação do cardápio e facilitar o processo de realização dos pedidos.

 💡 O que foi desenvolvido

* 🌐 Site responsivo para apresentação do cardápio
* 📱 Interface adaptada para dispositivos móveis
* 🍔 Catálogo de produtos
* 🛒 Carrinho de pedidos
* ➕ Seleção de adicionais
* 📋 Formulário para dados do cliente
* 💬 Envio do pedido através do WhatsApp
* 🎨 Aplicação da identidade visual da hamburgueria
* 📲 Publicação do projeto utilizando GitHub Pages

 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e responsividade
* **JavaScript** — interatividade, carrinho e lógica dos pedidos
* **Git** — controle de versão
* **GitHub** — armazenamento e gerenciamento do projeto
* **GitHub Pages** — publicação do site

🔗 **[Acessar o projeto Burger 301](https://burger-301.github.io/Burger-301/)**
